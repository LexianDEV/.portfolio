## GoExport

GoExport is a tool for a software called **"Wrapper Offline"** (based on GoAnimate's legacy codebase, Legacy Video Maker). Its primary purpose is to export videos by recording them using FFMPEG and open source drivers, which utilize the `dshow` filters to act as screen capture.

This software, at the time of writing, is a Windows-exclusive command-line-based application, with a GUI hopefully coming in the future.

[Check out the website](https://goexport.lexian.dev/) and [Github](https://github.com/GoExport/GoExport/)
